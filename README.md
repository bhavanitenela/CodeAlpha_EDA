# CodeAlpha EDA

## Project Overview
This project performs Exploratory Data Analysis on a student performance dataset using Python and Pandas.

## Objective
The objective is to explore the dataset, understand its structure, identify missing values, calculate statistics, and analyze student performance.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
The dataset contains student information such as:
- Name
- Gender
- Age
- Study Hours
- Attendance
- Marks

## Analysis Performed
1. Displayed the first five rows.
2. Checked the number of rows and columns.
3. Examined dataset information and data types.
4. Generated statistical summary.
5. Checked for missing values.
6. Calculated average, highest, and lowest marks.
7. Calculated average study hours and attendance.
8. Identified the student with the highest marks.
9. Created a student marks bar chart.

## Output
The analysis results are displayed in the terminal and a bar chart is generated using Matplotlib.
